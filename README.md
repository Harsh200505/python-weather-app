# 🌦️ Python Weather App

A simple and interactive **Weather Application** built with **Python and Flask** that retrieves real-time weather information using a weather API.

Users can search for a city and view current weather information through a clean and responsive web interface.

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Display current temperature
- ☁️ Show weather conditions
- 💧 Display humidity
- 💨 Show wind information
- 🔄 Real-time API-based weather data
- 📱 Responsive web interface
- ⚡ Fast Flask backend
- 🔐 Secure API key configuration using environment variables

## 🛠️ Tech Stack

- Python
- Flask
- Requests
- Weather API
- HTML5
- CSS3
- Jinja2
- python-dotenv

## 🔌 API Integration

The application communicates with a weather API to retrieve current weather information based on the city entered by the user.

The API key is stored securely in an environment variable rather than directly inside the source code.
